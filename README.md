## About SchemeSetu

**SchemeSetu** is a student-built prototype developed by **Team
AutoNova** as part of the **Internal Smart India Hackathon (SIH)** at
**Inderprastha Engineering College, Ghaziabad**.

The idea addresses a common problem: many citizens, especially people in
**rural and underserved areas**, are unaware of government schemes and
welfare programmes for which they may be eligible.

SchemeSetu aims to simplify this process by using citizen-provided
information and AI-assisted processing to identify potentially relevant
government schemes and present the information in a more accessible way.

> **Note:** SchemeSetu is currently only a prototype and is **not an
> official Government of India website or service**. The name is
> provisional and may be changed in the future to avoid possible naming,
> trademark, or pre-existing registration conflicts.

## How It Works

1.  The citizen provides relevant information through the web
    application.
2.  The information is processed through the application's AI and
    automation workflow.
3.  Scheme data is categorized and evaluated against the citizen's
    profile.
4.  Potentially relevant schemes are identified and presented to the
    citizen.
5.  The system can use automated communication and data services for
    processing and responses.

## Technology Stack

-   **Frontend:** React, TypeScript, Vite
-   **UI:** Tailwind CSS, Lucide React, Motion
-   **AI:** Google Gemini API
-   **Automation:** n8n
-   **Backend/Runtime:** Node.js, Express.js
-   **Data:** Structured government-scheme information
-   **Configuration:** Environment variables

## Key Features

-   Citizen-focused government scheme discovery
-   AI-assisted eligibility and scheme matching
-   Automated processing through n8n
-   Structured scheme data categorization
-   Responsive and accessible web interface
-   Light and dark theme support
-   Architecture designed for future expansion

## Getting Started

### Prerequisites

-   Node.js and npm
-   Google Gemini API key
-   n8n access if reproducing the automation workflow

### Installation

``` bash
git clone https://github.com/Satvik-Creations/SchemeSetu.git
cd SchemeSetu
npm install
```

Configure your environment variables using `.env.example`, then start
the development server:

``` bash
npm run dev
```

For a production build:

``` bash
npm run build
```

> **Security:** Never commit real API keys, credentials, webhook
> secrets, or other sensitive information to the repository.

## Smart India Hackathon

SchemeSetu has been developed as part of the **Internal Smart India
Hackathon (SIH)** with a focus on using technology to improve awareness
and accessibility of government welfare schemes.

The current version is a **prototype**, intended to demonstrate the
concept and its potential for future development.

## Future Scope

-   More government schemes and regularly updated datasets
-   Regional-language and multilingual support
-   Better eligibility-rule validation and explainable matching
-   Direct links to official government application portals
-   Accessibility improvements for low-connectivity environments
-   Additional communication channels
-   Future integration with verified official government systems

## Disclaimer

SchemeSetu is an **independent student project and prototype**. It is
not an official government portal, nor does it represent any government
department.

Users should verify scheme details and eligibility through the relevant
**official government sources** before applying.
